# abinashphys.github.io

Academic website of **Abinash Das**, Ph.D. student in Physics at the Georgia Institute of
Technology and member of the Center for Relativistic Astrophysics.

**Live site:** https://abinashphys.github.io

Built with [Astro](https://astro.build/) and deployed to GitHub Pages.

```bash
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # production build in dist/
```
